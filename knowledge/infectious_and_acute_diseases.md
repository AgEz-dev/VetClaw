> **官方发布机构**：Merck & Co.（Kenilworth, NJ, USA）；WSAVA（世界小动物兽医协会）；AAHA（美国动物医院协会）。
> **适用范围**：宠物主人科普与家庭分诊参考，不构成诊疗方案，不替代执业兽医诊断。
> **查验日期**：2026-10-07。

## 猫瘟（FPV，猫泛白细胞减少症）

> 出处：Merck Veterinary Manual — Feline Panleukopenia；WSAVA 猫疫苗指南 2024。

猫瘟由猫细小病毒（FPV）引起，与犬细小病毒（CPV）同属细小病毒科，对环境和常见消毒剂抵抗力极强，可在污染环境存活数月到一年。**未接种疫苗的幼猫最易感，病死率可达 50%-90%。**

病毒优先攻击快速分裂的细胞，破坏肠道绒毛上皮与骨髓造血细胞，导致白细胞（尤其中性粒细胞）急剧下降，因此得名"泛白细胞减少症"。康复猫仍可长时间排毒，是隐性传染源。

**典型体征**：突发高热（40-41°C）、精神沉郁、食欲废绝；剧烈呕吐（黄绿色或带泡沫）；腹泻（后期带血）；脱水、腹痛、蜷缩姿势。幼猫可无前驱症状突然死亡。

**家庭判断要点**：未完成疫苗的幼猫出现"精神差 + 反复呕吐 + 拒食"三连，须按猫瘟急症处理，不要在家观察。

| 项目 | 参考区间 / 表现 | 危险信号 |
|---|---|---|
| 易感年龄 | 未免疫幼猫 2-6 月龄 | < 3 月龄病死率最高 |
| 潜伏期 | 2-14 天 | 潜伏期即可排毒 |
| 体温 | 40-41°C | > 41°C，或后期转为低体温 |
| 白细胞（WBC） | 正常 5.5-19.5 ×10⁹/L | < 2.0 ×10⁹/L 提示重症 |
| 排毒途径 | 粪便、呕吐物、尿液、唾液 | 康复后仍可排毒数周 |
| 环境存活 | 室内可存活数月至一年 | 需专用消毒剂（含氯/加速过氧化氢） |

## 犬细小病毒（CPV，犬细小病毒性肠炎）

> 出处：Merck Veterinary Manual — Canine Parvovirus Infection；WSAVA 犬疫苗指南 2024。

犬细小病毒（CPV）是幼犬最常见的烈性肠道传染病，经粪口途径传播。病毒在肠道隐窝上皮与心肌细胞复制，造成肠黏膜大面积脱落与菌血症。**未免疫幼犬（6 周龄-6 月龄）风险最高，急性病例可在 24-48 小时内因脱水与败血症死亡。**

**典型体征**：突发精神沉郁、拒食；剧烈呕吐；**血样腹泻伴特征性腥臭**；迅速脱水、腹部疼痛；体温可能升高或后期下降。

**心肌型（较少见）**：多见于 8 周龄内幼犬，可表现为突然呼吸困难、心力衰竭甚至猝死。

**家庭判断要点**：幼犬出现"番茄酱样血便 + 呕吐 + 精神崩塌"，无论是否接种过疫苗，立即急诊。

| 项目 | 参考区间 / 表现 | 危险信号 |
|---|---|---|
| 易感年龄 | 6 周龄-6 月龄未免疫幼犬 | < 8 周龄心肌型可猝死 |
| 潜伏期 | 4-14 天 | 潜伏期即排毒 |
| 粪便性状 | 先软便后血便、腥臭 | 番茄酱样血便为重症 |
| 脱水程度 | 皮肤弹性下降 | 捏皮回弹 > 2 秒须静脉补液 |
| 白细胞（WBC） | 正常 6.0-17.0 ×10⁹/L | 白细胞降低提示预后差 |
| 传播途径 | 粪口、污染环境/鞋底/草地 | 病毒耐环境，需彻底消毒 |

## 犬瘟热（CDV）

> 出处：Merck Veterinary Manual — Canine Distemper；WSAVA 犬疫苗指南 2024。

犬瘟热由犬瘟热病毒（CDV，副黏病毒科）引起，是多系统、高致死性传染病，经飞沫与分泌物传播。病毒先侵犯呼吸道淋巴组织，随后扩散至呼吸道、消化道、皮肤与中枢神经系统。

**分阶段体征**：
- **早期（呼吸道/消化道）**：发热（双相热）、眼鼻脓性分泌物、咳嗽、呕吐腹泻。
- **中期（皮肤）**：鼻镜与脚垫增厚变硬（"硬脚垫症"）、腹股沟脓疱。
- **后期（神经）**：抽搐、咀嚼肌节律性抽动（"嚼口香糖样"）、共济失调、瘫痪。

**神经症状一旦出现，预后极差且多不可逆。** 幼犬感染可伴牙釉质发育不全（"犬瘟齿"）。

| 项目 | 参考区间 / 表现 | 危险信号 |
|---|---|---|
| 易感年龄 | 3-6 月龄未免疫幼犬 | 未免疫成犬亦可感染 |
| 体温 | 双相热：先 39.5-41°C，短暂下降后再升 | 持续高热 + 神经症状 |
| 眼鼻分泌物 | 由浆液性转为脓性 | 角膜混浊、脓性分泌物 |
| 神经症状 | 抽搐、肌颤、共济失调 | 出现即预后不良 |
| 存活后遗症 | 神经损伤、牙釉质缺损 | 可能终身抽搐 |
| 传播途径 | 飞沫、眼鼻分泌物、尿液 | 康复后仍可排毒数周 |

## 猫传染性腹膜炎（FIP）

> 出处：Merck Veterinary Manual — Feline Infectious Peritonitis；AAHA/AAFP 猫科诊疗指南。

猫传染性腹膜炎（FIP）由猫冠状病毒（FCoV）在个体内突变后致病，并非普通肠道冠状病毒直接传染。多见于**幼猫（< 2 岁）、老年猫与免疫力低下猫**，纯种猫与多猫环境风险更高。

**两型表现**：
- **湿性（渗出型）**：腹腔/胸腔积液，腹围进行性增大（"蛙腹"），呼吸困难，发热（抗生素无效的顽固发热）。
- **干性（非渗出型）**：脏器肉芽肿，可累及眼（葡萄膜炎、虹膜变色）、神经（共济失调、抽搐）、肾肝。

**关键鉴别**：顽固性发热 + 抗生素治疗无效 + 腹围增大/葡萄膜炎，是 FIP 的高危组合。确诊需结合积液分析、冠状病毒抗体滴度与影像学。

| 项目 | 参考区间 / 表现 | 危险信号 |
|---|---|---|
| 高发年龄 | < 2 岁幼猫、> 10 岁老年猫 | 多猫环境/纯种猫风险高 |
| 体温 | 39.5-41°C 顽固发热 | 抗生素治疗无效的持续发热 |
| 湿性体征 | 腹围增大、胸腔积液、呼吸困难 | 腹围短期明显增大 |
| 干性体征 | 葡萄膜炎、虹膜变色、神经症状 | 眼部/神经受累预后差 |
| 血液指标 | 总蛋白升高、白球比（A/G）下降 | A/G < 0.6 高度怀疑 |
| 确诊手段 | 积液分析、抗体滴度、影像学 | 不可仅凭抗体阳性确诊 |

## 急性胰腺炎

> 出处：Merck Veterinary Manual — Pancreatitis in Small Animals；ACVIM 共识声明。

急性胰腺炎是犬猫常见的急腹症，由胰酶在腺体内异常激活导致自身消化。**诱因包括高脂饮食（尤其犬偷吃油腻食物）、肥胖、某些药物、胆道疾病与外伤。** 猫的诱因常不明确，且症状更隐匿。

**典型体征**：剧烈腹痛（犬呈"祈祷姿势"——前肢伏地、后肢站立、腹部贴地）、呕吐、食欲废绝、精神沉郁；猫常仅表现为嗜睡、拒食、体重下降。

**重症风险**：可并发全身炎症反应综合征（SIRS）、多器官衰竭、胰腺坏死与腹膜炎，死亡率高。

| 项目 | 参考区间 / 表现 | 危险信号 |
|---|---|---|
| 常见诱因 | 高脂饮食、肥胖、胆道疾病、外伤 | 节日偷食油腻剩菜后发病 |
| 腹痛姿势 | 犬"祈祷姿势"，腹部拒按 | 腹部剧痛、拒绝触碰 |
| 呕吐 | 频繁呕吐，进食后加重 | 呕吐 > 4 小时不止 |
| 猫的非典型表现 | 嗜睡、拒食、体重下降 | 猫持续拒食 > 24 小时 |
| 实验室指标 | 犬 cPL / 猫 fPL 特异性脂肪酶升高 | 脂肪酶显著升高 + 低钙 |
| 影像 | 腹部超声见胰腺肿大/回声改变 | 出现积液提示重症 |

## 猫下泌尿道综合征（FLUTD）

> 出处：Merck Veterinary Manual — Feline Lower Urinary Tract Disease；AAFP/ISFM 猫泌尿系统指南。

猫下泌尿道综合征（FLUTD）是猫排尿异常的统称，包括特发性膀胱炎、尿结石、尿栓子与感染。**公猫尿道细长，最危险的是"尿道完全阻塞"——可在 24-48 小时内因高钾血症与急性肾衰致死，属绝对急症。**

**典型体征**：频繁进出猫砂盆、蹲很久却尿不出（"空蹲"）、排尿时嚎叫、尿频尿少、血尿、在猫砂盆外排尿、频繁舔舐外阴。**完全阻塞时猫会精神沉郁、拒食、呕吐，甚至昏迷。**

**家庭判断要点**：公猫反复空蹲且无尿（或仅几滴），立即急诊导尿，不能等到第二天。

| 项目 | 参考区间 / 表现 | 危险信号 |
|---|---|---|
| 高发群体 | 中年、肥胖、室内、公猫 | 公猫完全阻塞风险最高 |
| 排尿表现 | 尿频、尿少、血尿、砂盆外排尿 | 反复空蹲却无尿 |
| 疼痛表现 | 排尿嚎叫、频繁舔外阴 | 排尿时惨叫 |
| 完全阻塞 | 腹围胀、触诊膀胱胀大 | 24-48 小时内可致死 |
| 实验室指标 | 血钾升高、肾指标（BUN/Cre）升高 | 高钾 + 急性肾衰 |
| 紧急处理 | 立即导尿解除阻塞 | 阻塞 > 24 小时预后差 |
